青空文庫との関係

個人が制作したリーダーであり、青空文庫の公式サービスではありません。作品を入力・校正し、公開を続けている皆さまに感謝します。

作品本文

収録本文は青空文庫から取得したテキストを加工せず収録しています。末尾に底本・入力・校正情報があります。作品と関係者の著作権フラグが「なし」の作品を選定しています。これは日本の情報に基づく選定で、世界各国での権利消滅を保証するものではありません。翻訳作品には原著と翻訳の権利があります。収録ファイルの取り扱い規準をご確認ください。許諾を得て青空文庫が公開している著作権存続作品は、目録には含みますが本文は同梱しません。

書誌データ

data/catalog.json と texts/index.json の書誌情報は、青空文庫の作品一覧 CSVを基に、項目抽出・作品選定・表記整形・JSON 化を行ったものです。提供元：青空文庫。ライセンス：Creative Commons 表示 4.0 国際（CC BY 4.0）。作品の選定には2022 年のアクセスランキング（XHTML 版）を使用しています。

通信と保存

本文をアップロードする機能やアクセス解析は組み込んでいません。サイトのファイルを取得する際には配信元と通信します。GitHub Pages は IP アドレスをログに記録します。「すぐに読める作品」（サイトに収録した作品）を開くときの URL も配信元へ送られます。旧版の ?book= URL は初回アクセス時には送信されるため、移行後の #book= URL を使ってください。

書体は端末に入っているフォント（明朝・ゴシック）を使い、外部からフォントは読み込みません。

保存先はブラウザ・サイトのアドレスごとに異なります。同一オリジンの別サイトからのアクセスを防ぐものではありません。ブラウザのデータ消去・プライベート閲覧・容量不足などで保存内容が失われる場合があります。別の端末やアドレスへの自動引き継ぎはありません。通信できない状態からの起動は保証していません。

不具合の報告

不具合のご報告・ご要望は、GitHub の Issues にお寄せください（投稿には GitHub のアカウントが必要です）。報告の際は、版（開発版。このページ上部に表示）、OS、ブラウザの版、操作手順、エラー表示を添えてください。本文をそのまま共有する必要はありません。

Issues の内容は誰でも閲覧できます。メールアドレスなどの個人情報や、読み込んだファイルの中身は書かないでください。
